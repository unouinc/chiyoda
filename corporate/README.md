- KV／MVVページのミッション・ビジョン文言（MVV確定後に差し替え）
- バリュー（策定中・4項目は仮置き）

- 拠点（千葉／君津／羽田／その他）の住所・電話

- 安全実績の数字（無事故日数・表彰・Gマーク等）※数字がなければブロック削除
- エイトパーキング公式サイトの有無・統合方針
- 採用サイトは別WF（recruit-site-wf.html は仮置き）
